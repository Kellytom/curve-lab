# Code of conduct

> **draft A** — a working draft, not a final text.

This project adopts the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We pledge to make participation a harassment-free experience for everyone,
regardless of age, body size, visible or invisible disability, ethnicity, sex
characteristics, gender identity and expression, level of experience,
education, socio-economic status, nationality, personal appearance, race,
religion, or sexual identity and orientation.

## Expected behaviour

- Be direct about the work and kind about the person.
- Assume the other person is acting in good faith until they show otherwise.
- Give a number, a command or a file path when you disagree about a fact.
- Accept that the maintainer decides the scope; "not now" is a complete answer.

## Unacceptable behaviour

Harassment, insults, sexualised language or imagery, sustained disruption,
publishing someone's private information, or dismissing a report of harm.

## Enforcement

Report a problem to the repository owner through GitHub. Reports are read
privately. The maintainer may warn, remove a comment, or block an account.

This code applies in the repository, its issues and pull requests, and anywhere
someone represents the project.
