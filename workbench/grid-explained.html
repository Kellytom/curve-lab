Grid explained

A denominator is a ruler, not the size of the drawing. String a few triangles together and you know exactly where you are and which way you face.

The short answer: yes. Each triangle step turns the heading by the same exact angle — cosine 4/5, sine 3/5 — and each step adds an exact vector. Position and heading at every node are exact, with no accumulated error. The denominator is only how that exact fraction is written down.

1 · Position and angle, without a denominator in sight

Gold dots are nodes; green ticks are the heading there. The node marked is at (52/25, 39/25) after three turns. It is not “about 2.08”; it is exactly 52 twenty-fifths and 39 twenty-fifths. A chain of these gives the same exactness at every node, which is what you asked for.

2 · What the denominator actually is

One unit is divided into 25 ticks. The node sits 52 ticks along and 39 ticks up. The denominator 25 is the number of ticks per unit; it does not make the drawing 25 units long. A 217-digit denominator is the same idea with a finer ruler: 217 digits of ticks, on a drawing that is still tens of chords across.

So when a report says “a very large grid”, it should say which ruler it means. The drawing is small; the ruler is fine.

3 · Grouping the turns changes the step count, not the angle

Both chains sweep the same 90°. The 1× chain needs 62 turns; the 2× chain needs 31 steps with two turns each. The exact ruler is fixed by the number of turns, 62, so both have denominator 312162. Grouping saves steps; it does not change the exactness or the ruler.

4 · The grid is the box, not the path

The box only grows while the curve is going out. At 90° the tangent is vertical, so x stops increasing; at 180° the tangent is horizontal, so y stops. After that the spiral curls inside the box. For this 270° chain the box is 79 × 79, while the path is 186 chords long. The grid needs the box, not the path.

For a full 360° the box is still 79 × 79; the path is 248 chords. A circle of radius R needs a 2R × 2R box and a 2πR path, so the box is about 1/π of the path. That is the factor the “large grid” phrasing was missing.

The three numbers, kept apart

drawing extentbox 39 × 40 for the 90° arc (path 62 chords); the 270° box is 79 × 79 with a 186-chord path
exact rulerthe denominator that makes every node an integer — 312162, 217 digits; a representation cost, not a drawing size
placement gridthe 3125 lattice a drawing is snapped to; measured worst error 2.1e-04 of a chord

What this means for the reports. “Needs a very large grid” is accurate only for the exact ruler at unit spacing. It is misleading for the drawing (a 79 × 79 box for a 270° volute) and for the placement grid (3125, error 2.1e-04). Say “the exact denominator is 217 digits” or “the box is 79 × 79”, not one phrase for both.

And the LAC. A chain that turns by the same angle every step is a circular arc. An LAC turns by growing multiples (0, 1, 2, …), so its ruler grows faster — cn(n+1)/2 — but the position and angle at each node are still exact. That is the case where “large” is earned.
