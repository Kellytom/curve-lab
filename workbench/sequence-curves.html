curve-lab · sequence curves

Sequence curves on the integer lattice

Five right-angle walks whose segment lengths come from a number sequence. The factorials give 24, 6, 2, 1; the triangular sums give T₄ = 10, T₃ = 6, T₂ = 3, T₁ = 1. Every vertex is integer because every step is an integer length along an axis.

The symmetric closure. The schedule 1, 2, …, n, −n, …, −1 closes exactly and returns to the origin. The return repeats each chord in reverse with the opposite sign, so the displacement cancels pairwise: Σ L k = −Σ L k = 0. The two passes share the same chords, so the return is drawn dashed on top of the outward pass. This is a closed walk, not a non-overlapping polygon; the point is the exact integer closure.
