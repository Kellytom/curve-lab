Euler spiral → cubic Bézier

The current cubic seam already uses the 2021 endpoint-parabola rule: the handle sits where the endpoint tangent meets the parabola. The editor below is the handle construction made draggable; the panels measure the current seam against the true Euler spiral, not a second fit.

What is being measured

The current seam's arm is

arm = |chord| / (3 cos²(θ/2)) = 2|chord| / (3(1 + cos θ))

which is exactly the intersection of the endpoint tangent with x = 1/3 − (3/4)y² on the normalized chord. So there is no separate fitted option to switch to; the comparison is a validation of the existing seam. The error is the maximum sampled normal distance from the cubic to the true Euler spiral; arclength is the true arclength normalized to chord 1.

Comparison

The asymptotic slope is taken from n=4, 8, 16. The n=1 symmetric fit is accidentally good, so it is not used to estimate the exponent. A slope near 5 is the claimed n⁵ behavior; doubling n should reduce error by about 32×.

Verdict

The rule is a good fitted seam and is already in use. The p-triple polygon and rational rails remain the exact route; this is a drawing approximation. It does not make handles integer, and it is not the bounding-parabola intersection method.

Source

Levien, “Cleaner parallel curves with Euler spirals” (2021), section “Euler spirals to cubic Béziers”; and “Secrets of smooth Béziers revealed” (2018).
