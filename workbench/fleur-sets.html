Fleur sets P01–P20

Twenty parameter sets from one source, drawn by one function: the set is data, not twenty programs.

What is shared. Every card is `grammar.study(opts)`: the same right half, mirror, band and no fill, so 20 studies make one hand rather than 20 special cases. Each has 26 spans and the port's nine corners; the parameter changes move the petals, the lance, the band and the foot, not the grammar. The rail error on each card is the fitted 25-unit rail, not a copy error.

The seam. Every set measures its own two centre-seam crossings on the built rails and declares them as contacts, so the halves are joined rather than merely touching. P01's measured pair matches the fixed pair in `study_01`; the other nineteen get theirs from `seam_contacts`. The clearance report is clean on all twenty.

Source: ornaments/assets/ornament_set.js, the study-01…study-20 rows, transcribed in curve_lab/fleur_sets.py.
