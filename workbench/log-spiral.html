The log spiral: an easy offset that is not an offset

The equiangular spiral r = a·e^(bθ) is famous for being self-similar. It is often said that its offset curves are log spirals too. Half of that is true, and the half that is false is the half the stem needs.

Fig. L1 · one spiral, a constant width that is not a spiral, and a scaling that is

The blue curve is a true constant-width parallel; the gold is the same spiral scaled. Only the gold one is a log spiral, and its width grows with the radius — the red bars are equal by construction, the gold gap is not.

Fig. L2 · the drift, measured

A log spiral has one constant: the angle between its tangent and its radius. Fit that angle on the constant-width parallel and it is not constant. The spread grows with d/r:

Exact zero would mean the parallel is a log spiral. It is not: at d/r = 0.02 the spread is 0.22°, and it rises in proportion to d/r.

What is exact

Scaling. Multiply the spiral by k and you get another log spiral with the same pitch. The width between them is measured along the normal and is proportional to the radius — a self-similar taper, exactly what a stem wants and exactly what a constant width is not.

The evolute. The centres of curvature trace another log spiral about the same origin; measured tangent-angle spread over four turns: 0.0000° — exact to sampling.

So the honest formulation: the log spiral's easy relation is similarity, not offset. Width that grows with the radius is exact; width that stays constant is not.

What this means for a stem

A log-spiral stem can carry an exact tapered width — two spirals with the same b and different a — with the width law w ∝ r. It cannot carry an exact constant width, and it is not on the integer lattice at all. If you need both a constant width and exactness, this curve is the wrong source; if you need a taper, it is the cleanest one in the catalogue.
