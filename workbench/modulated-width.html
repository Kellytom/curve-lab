Modulated width

Formerly called Stage IV. The width changes along the spine; the rails are not equidistant, so this is not a parallel offset.

The law. w(u) = w0 (1 + a · 64 u³ (1−u)³). The cubic bump has a triple root at both ends, so the width, its slope and its curvature all meet the plain stroke with no step. The three cards show plain, widening and narrowing. The full measured set is the old Stage IV source page (10 plates); serve it from ../ornaments on port 8001.

Why it is a separate track. A parallel offset keeps the two rails a constant distance apart; here the width is a function. The 2× offset rule does not apply. This is an advanced width-modulation target, not a side issue and not a failure; it is simply outside the parallel-offset grade.
