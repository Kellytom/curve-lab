# Changelog

All notable changes are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/). There are no versioned
releases yet, so entries are grouped by date.

## [Unreleased]

_2026-11-18._

### Added

- `app/src/content/docs/docs/concepts.md`: one page defining Euler curve, exact curve, PH, grid,
  bend, arc, chord, flat spot, crossing pair, loop, step, symmetry, rails,
  plate, section, junction and contact.
- `app/src/content/docs/docs/worked-example.md`: one curve from its polynomials to its grid, arc,
  bend, crossing pairs, figure and checks.
- `app/src/content/docs/docs/state-of-the-work.md`: what is proved, what is draft, and what is next,
  each claim with the command that checks it.
- `llms.txt` and `llms-full.txt`: a short map and the full text for agents,
  generated by `scripts/llms_full.py` and checked by `tests/test_llms.py`.
- `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, this changelog,
  `.editorconfig`, and issue and pull-request templates.
- `scripts/stamp_draft.py`: the `draft A` label on every outward page, enforced
  by `tests/test_draft_label.py` and re-applied by `scripts/build-pages.py`.
- An `about` page in the Astro app, linking the repository's own documents.
- Names, importance, rotation and pieces now live in SQLite through Prisma;
  the JSON registry is the seed and the notes file is an export.
- The Gallery of Illuminations at `/illuminations`: 241 curves, each bordered by
the same curve three times a side, numbered once.

### Changed

- Astro 7.4.13 on Node 24.22.3; the app requires Node 22.23 or newer.
- Names, ratings, turns, pieces and stars moved from JSON files to SQLite through
  Prisma; the JSON files are seed and export.

- Prose says **Euler curve**; `clothoid` remains where it names the vendored
  library, a file or a backend (`Clothoids`, `pyclothoids`, `clothoid_api.cpp`).
- The README leads with the app and the lab; the native build is described as
  the engine's requirement, not the project's first step.
- Public docs address "the author", not "the operator".
- The book's navigation covers `STRUCTURE.md`, `CONCEPTS.md`,
  `CURVATURE-POWER-CURVES.md`, `SELF-INTERSECTION-REFERENCES.md` and
  `PH-QUINTIC-REVIEW.md`.

### Fixed

- The two save backups are registered as optional datasets, so the data audit
  no longer fails on a machine that has saved a curve.
- `curves/index.json` and 15 curve notes regenerate from their records; a stale
  crossing count of 4 became the record's 3.
- `mkdocs build` passes in strict mode; the G3 page names the lab pages instead
  of linking to files outside the book.

### Added

- SQLite through Prisma as the record, with a counted migration and
  `scripts/check-db.mjs`.
- Automatic snapshots, `npm run backup`, `npm run restore`, WAL, and a
  five-minute GitHub sync of the exports.
- `SandboxCurve` and `PlateStar`; the sandbox saves and the plate stars are rows.
- The book's "Where the data lives", "If something goes wrong" and "Run your own
  instance" pages.

### Removed

- Eight raw session transcripts moved from `docs/` to `archive/notes/`, with a
  README explaining what the folder is.
- The commit author email `kelly.aquinas.tom@gmail.com` was removed from the
  history and replaced with the GitHub noreply address.
