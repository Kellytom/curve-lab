# state/

What is true **this week**, as opposed to what is true in general.

| file | what it holds |
|---|---|
| `HANDOFF.md` | current truth: local, remote, tests, git, risks, the next move. Written by `/fhandoff`; do not hand-edit the state lines |
| `BACKLOG.md` | execution detail for W01–W26, the work items on the board |
| `SESSIONS.md` | the proposed order for the next sessions |
| `WORK.md` | the P/W/D registers and the spine layer's promotion gate |
| `STATUS.md` | what works today, what is not wired |

These are superseded regularly and grow stale on purpose — that is the point of
keeping them apart from `docs/`, which holds the durable reference and the
design writing. They are not part of the published mkdocs book.

Start at `HANDOFF.md`. It is the second thing every session reads.
