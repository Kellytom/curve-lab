# ai-news — a bootstrap pack for another AI

You are reading a pack, not the repository. The repository is next to it and is the record;
this folder exists so you can get oriented in minutes instead of hours.

## Read in this order

1. **`00-start-here.md`** — what the project is, what is true right now, and where the truth lives.
2. **`01-map.md`** — the repository map, with file references.
3. **`02-recent-work.md`** — the last 40 commits, newest first.
4. **`03-data.md`** — the data model, the counts, and the trap in it.
5. **`07-questions.md`** — the known faults and the decisions nobody has made. This is where
   your criticism is most useful.
6. **`08-glossary.md`** — the project's words, one line each, so you do not import the wrong ones.
7. **`06-code.md`** — six short excerpts with exact file:line references, the code that matters.
8. **`04-plots/`** — four small SVGs: families, the shape grid, grids, ratings.
9. **`05-svgs/`** — four plates as the collection draws them today.

## What this pack is not

- It is not a substitute for the registers: `state/REGRESSIONS-int.md` (every fixed fault and the
  test that guards it) and `state/DESIGN-int.md` (every settled decision and why).
- It is not a summary of everything. It is the shortest path to a useful opinion.
- It is regenerated by `scripts/ai_news.py` where it can be, and hand-written where judgement is
  needed. If a number here disagrees with `data/curves.json`, the data wins and this pack is wrong.

## What would help most

1. Read `07-questions.md` and say which fault matters and which does not.
2. Read `06-code.md` and say whether the plate law (inside capped, outside wide) is honest.
3. Read `03-data.md` and say whether the data model can still be trusted at 393 curves.
