# The founder's desk

Screenshots, traces, photographs and hand sketches go here, and they are
**tracked**, so they are backed up with everything else. That is the point of
the folder: the repository root ignores stray images, so a file dropped there is
not backed up, while a file dropped here is.

- `founder/screens/` — screenshots and traces, named for what they show:
  `half-heart.png`, `euler-tangency.png`.
- `founder/notes/` — anything written that is not a document yet. A note that
  keeps being useful graduates into `docs/`.

The naming rule is: the name says what the thing is, no dates, no versions. A
new version of a file replaces the old one; the git history holds the old one.

A screenshot worth keeping is usually worth a line in `state/HANDOFF-int.md`: what
it showed, and what it settled.
